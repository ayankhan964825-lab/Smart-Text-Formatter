Foundation

Introduction to Complex Analysis

Complex analysis studies functions of complex variables z = x + iy, where i = √-1.

∮

Analytic Functions

Functions differentiable w.r.t. complex variables. They have remarkable properties: infinite differentiability and power series representation.

∫

Contour Integration

Integration along paths in the complex plane. This leads to powerful results that simplify many difficult real integrals.

The Power

Why Complex Integration is Powerful

In real calculus, evaluating certain integrals can be extremely difficult. By extending into the complex plane, many become simple.

Prerequisites

Basic Definitions

Complex Function

f(z) = u(x,y) + iv(x,y) where z = x + iy. u = real part, v = imaginary part.

Analytic Function

Differentiable at every point in a region. Also called holomorphic. Examples: z², ez, sin(z).

Contour

A smooth curve/path in the complex plane along which integration is performed. Can be a line, circle, or curve.

Closed Contour

A path whose start and end points are the same. Example: circle, closed loop. Critical for Cauchy's theorem.

Simply Connected

A region where any closed contour can be shrunk to a point without leaving the region. No holes allowed.

Derivative

f'(z) = limΔz→0 [f(z+Δz) − f(z)] / Δz. If this limit exists, the function is differentiable.

Cauchy Integral Theorem

If f(z) is analytic everywhere inside and on a closed contour C in a simply connected region, then:

∮C f(z) dz = 0

Key Insights

The integral depends only on analyticity — NOT the contour shape.
No singularities inside C means the integral is always zero.
Analogous to conservative vector fields in real calculus.
Discovered by Augustin-Louis Cauchy (1825).
∮

Conditions of the Theorem

For the Cauchy Integral Theorem to hold, ALL of the following must be satisfied:

✓ f(z) must be analytic inside the region
✓ f(z) must be analytic on the boundary (contour C)
✓ The contour C must be closed
✓ The region must be simply connected (no holes)
✓ No singularities inside the contour

Proof Outline

Step 1: Write f(z) = u(x,y) + iv(x,y) and dz = dx + idy
Step 2: Expand ∮C f(z)dz = ∮C(u dx − v dy) + i∮C(v dx + u dy)
Step 3: Apply Green's Theorem → convert line integrals to double integrals over R
Step 4: Use Cauchy–Riemann equations: ∂u/∂x = ∂v/∂y and ∂u/∂y = −∂v/∂x
Step 5: Both double integrals = 0 ⇒ ∮C f(z) dz = 0 ✓

Cauchy Integral Formula

If f(z) is analytic inside and on C, and 'a' is any point inside C:

f(a) = (1/2πi) ∮C f(z)/(z−a) dz

Why It Matters

Value at any interior point determined by boundary values
Analytic functions are infinitely differentiable
Leads to Taylor series expansions

Worked Examples

Applying the theorem to evaluate contour integrals of analytic functions:

Ex 1∮C z² dzf(z)=z² is a polynomial — analytic everywhere → = 0
Ex 2∮C (3z+2) dzf(z)=3z+2 is linear — analytic everywhere → = 0
Ex 3∮C ez dzf(z)=ez is exponential — analytic everywhere → = 0
All polynomial, exponential, and trigonometric functions are analytic everywhere in the complex plane. By Cauchy's Theorem: their closed contour integrals = 0.

What We Learned

1. Integral is Zero: If a function has no breaks or sharp points inside a closed path, its integral is zero.
2. Inside Value: We can find the value of a function at any inside point using only its boundary values.
3. Path Independence: The path you take does not matter — only the function matters.
4. Real-World Use: This helps solve very hard math problems easily in Physics, Engineering, Signal Processing & Quantum Mechanics.

Wrapping Up

Conclusion & References

The Cauchy Integral Theorem is a cornerstone of complex analysis. It shows that analytic functions have very special behavior — their integrals over closed paths are always zero. This one result leads to the Cauchy Integral Formula, Residue Theorem, Taylor Series, and Laurent Series. It is used across mathematics, physics, and engineering to solve problems that would otherwise be extremely difficult.
