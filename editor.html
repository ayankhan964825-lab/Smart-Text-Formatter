🆘 Common Issues
📱 App Not Loading

Try clearing cache: Ctrl + Shift + R to hard reload. This clears all cached data and should fix loading issues.

🤖 AI Assistant Not Working

If the AI is unresponsive, check your API key in settings. Ensure it is valid and has not exceeded its quota.

📝 Complex Formatting (Tables & Data)

Our Smart AI is highly capable of formatting complex data and tables! If raw text looks broken, just ask the AI Assistant to "convert this into a clean table" and watch the magic happen.

📊 Export Not Working

Make sure you have text in the preview pane. Exporting requires the generated HTML to be fully loaded.

🔧 General Troubleshooting Steps
  1. Try refreshing the page (Ctrl+Shift+R or Cmd+Shift+R)
  2. Clear browser cache and cookies
  3. Check your internet connection
  4. Try a different browser (Chrome/Edge recommended)
  5. Re-enter your API key
  6. Contact support if issue persists
