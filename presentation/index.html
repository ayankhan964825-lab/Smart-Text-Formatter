The Challenge

Manual formatting is broken.

⏳

Time-Consuming

Hours spent manually adjusting headings, spacing, and fonts across long documents.

🔀

Inconsistent

Different heading levels, font sizes, and spacing create unprofessional results.

🚫

No Browser Solution

No lightweight, browser-based tool auto-detects document structure and applies formatting.

The Solution

Smart Text Formatter

A web-based application that intelligently reads, understands, and formats unstructured text documents — powered by AI and pure Object-Oriented Design.

🔍 Auto Structure Detection ⚡ Real-Time Preview 🎨 Custom Rules Engine 🤖 Gemini AI Integration 📄 PDF & Word Export 🌐 100% Browser-Based

Design Philosophy

Why Object-Oriented Design?

01

Modularity

Each processing stage is a self-contained class with clear boundaries and single responsibility.

02

Reusability

Classes can be instantiated with different configurations — custom rules, different AI models, export formats.

03

Maintainability

Change one module without breaking others. Fix the RuleEngine without touching the StructureDetector.

04

Testability

Each class can be unit-tested in isolation — mock inputs, verify outputs, measure performance.

Core Concepts

OOP Principles in Action

🔒

Encapsulation

Each class hides its internal data. TextProcessor privately manages rawText; RuleEngine encapsulates defaultRules.

🎭

Abstraction

app.js calls formatText() without knowing if it uses AI or heuristic engine. Complexity is hidden.

🧬

Inheritance Ready

Architecture supports extension — a MarkdownDetector could extend StructureDetector.

🔄

Polymorphism

Both AIFormatter and the heuristic pipeline process input similarly — the controller doesn't care which runs.
