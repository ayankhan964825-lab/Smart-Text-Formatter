Core Engine

AI-Powered Formatting

01

Gemini 2.5 Flash API

Sends raw text to Google's Gemini AI with a detailed system prompt. AI classifies every paragraph into headings, body text, tables, lists, equations, and code blocks.

02

Chain-of-Thought Reasoning

AI thinks step-by-step before formatting: first extracts style from reference PDF, then maps content to sections, then assembles the final document.

03

Content Preservation

The AI never rewrites user text. It only organizes and formats — fixing typos and removing AI-generated fluff like "Sure! Here is your document..."

04

Self-Healing JSON

If Gemini returns broken JSON, the system automatically sends it back for correction — ensuring the formatting never crashes.

Templates & Smart Alerts

📋 5 Built-in Templates

📄 General 🔬 Research Paper 📝 Assignment 📋 Project Report 📰 More...

Each template has a predefined skeleton with required and optional sections. Users can customize fonts, sizes, and spacing per template.

If the selected template (e.g. Research Paper) is missing an "Abstract", the system alerts you. You can either manually paste your missed content to format it, or auto-generate it using Gemini.

Robustness

Edge Cases & Error Handling

🔑

API Key Rotation

Multiple API keys for Gemini, iLovePDF, and Unstructured.io. When one key hits its quota limit, the system automatically rotates to the next available key.

🔄

JSON Self-Healing

If the AI returns malformed JSON, the system sends the broken output back to Gemini with the error message, asking it to fix the syntax automatically.

🧹

AI Fluff Stripping

Pre-processor automatically removes AI chatbot wrapper text like "Sure! Here is your document..." in both Hindi and English before formatting.

🛡️

Graceful Fallbacks

Custom API key exhausted → auto-fallback to server proxy. PDF backend down → fallback to browser print. Local proxy fails → fallback to Vercel production.

📊

Java Analytics Edge Cases

Handles empty body, invalid JSON, missing 'text' field, empty text strings, and unexpected server errors — each returning a structured error response.

✅

Zero Plagiarism Risk

The AI only formats text, it does not rewrite it. Unless "Auto-Generate" is explicitly used, the final document's plagiarism score remains exactly the same as (or less than) the user's input.
