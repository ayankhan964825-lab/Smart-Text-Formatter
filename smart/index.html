The Core Challenges

The Formatting Struggle

Modern document creation suffers from severe inefficiencies. Working with raw text and exported PDFs presents two critical bottlenecks:

⏳

Manual Tedium

Creating professional documents requires repetitive manual effort. Highlighting text, enforcing consistent fonts, aligning paragraphs, and repeatedly switching formatting styles wastes hours of human potential.

⚠️

OCR & Data Noise

Copying data from scanned PDFs, Google Lens, or messy websites introduces severe artifacts. Random line breaks, broken text references, and floating page numbers like `[24]` ruin document integrity.

Our Solution

AI Smart Text Formatter

An AI-driven web application that automatically structures, cleans, and styles your text instantly. We leverage Generative AI algorithms to turn raw messy data into a clean document.

The Tech Stack

Instead of using heavy and slow frameworks like React or Node.js, we coded everything in raw, basic web technologies to make it incredibly fast.

🌐 HTML5
🎨 CSS3 (Flexbox & Variables)
⚙️ Vanilla JavaScript (ES6+)
HTML: Provides the semantic skeleton layout.
CSS: Uses variables for light mode and soft shadows.
JS: Uses the Fetch API to talk to AI directly.
🔒

100% Private

Zero Servers. Zero Databases. This application is a "Static Client-Side Application".

It runs entirely on your own laptop or phone's browser. This guarantees your important documents are never uploaded or saved on our servers.

💾 Keeps settings via your LocalStorage.
🛡️ Maximum data privacy for users.
⚡ Opens instantly without loading times.

The API Layer

Connecting to Gemini AI

We use Google's Gemini 2.5 Artificial Intelligence to process raw text like a human editor.

1

Send the Text

  • JS sends your ugly text safely to Google API.
2

JSON Prompting

  • We command the AI to reply ONLY in a strict machine-readable format (JSON).
3

Re-Building

  • Our program reads this JSON data and re-creates beautiful paragraphs in the HTML.
